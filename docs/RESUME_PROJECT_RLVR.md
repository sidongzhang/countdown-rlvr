# TinyZero RLVR项目简历写法

本文只使用仓库代码与实际实验日志中的事实，不虚构模型规模、训练步数、效果或个人贡献。推荐把项目定位为“可验证推理强化学习系统与算法诊断”，而不是简单复刻TinyZero或宣称提出了新算法。

## 一页简历版

**项目名称：面向可验证推理的LLM强化学习训练与评测系统**

**技术栈：Python、PyTorch、veRL、Ray、vLLM、FSDP、GRPO、PPO/GAE、Qwen2.5**

### 项目介绍

基于TinyZero与veRL改造Qwen2.5-1.5B-Instruct的Countdown任务RLVR训练链路，在2×RTX 4090D 48GB上完成标准GRPO、零方差自适应重采样和PPO基线实验；围绕规则奖励安全性、无效优势样本、采样多样性与训练成本建立可复现的评测与诊断流程。

### 核心工作

- 重构Countdown规则奖励，使用AST白名单与Fraction精确运算替代`eval`，校验数字使用次数、运算符、表达式合法性和结果正确性，并设计0/0.1/0.2/1.0分层奖励。
- 修改veRL的GRPO优势计算与训练循环，检测组内奖励零方差Prompt并按需重新rollout；修复浮点残差造成的伪非零优势和训练步数off-by-one问题，增加零方差率、有效优势Token比例及重采样恢复率等诊断指标。
- 构建固定512题、每题5次采样的pass@1/pass@5评测链路，通过固定数据划分、DataLoader与验证随机流对齐标准GRPO、Adaptive GRPO和PPO实验。
- 配置并跑通带独立Critic的PPO/GAE基线，通过FSDP、Gradient Checkpointing、CPU Offload与vLLM显存配额在双卡环境容纳Actor、Reference、Rollout和Critic，并对齐每步64×8=512条Response的采样预算。

### 项目成果

- 标准GRPO训练100步后，pass@1由5.08%提升至29.69%，pass@5由16.80%提升至31.84%；训练和验证过程中未出现OOM或NaN。
- Adaptive GRPO将平均有效优势Token比例由标准组的34.65%提高到41.85%，平均最终零方差组比例由64.20%降至57.08%，但平均Step耗时增加34.02%，100步最终精度与标准GRPO基本持平；据此定位出后期重采样恢复率从62.42%衰减至2.47%的边际收益问题。
- 在相同60步与30,720条训练Response预算下，PPO、标准GRPO的pass@1分别为23.63%、26.37%，pass@5分别为37.30%、32.03%；结合PPO第60步策略熵1.841和Critic Explained Variance -0.047，分析出PPO“候选覆盖率更高、单次命中率更低”的探索—利用权衡。
- PPO前60步平均耗时53.113秒/步，为标准GRPO的2.24倍；独立监控捕获PPO两卡峰值显存48,350/47,650MiB，为后续Critic优化和算法选型提供量化依据。

## 更精简的投递版

如果简历空间有限，可以压缩为下面三条：

- 基于TinyZero/veRL搭建Qwen2.5-1.5B Countdown RLVR训练与pass@k评测流程，使用AST白名单和Fraction实现安全分层奖励，在2×4090D 48GB完成GRPO与PPO对照实验。
- 针对GRPO后期组内奖励趋同问题，实现零方差Prompt检测与选择性重采样，修复浮点残差导致的伪优势；有效优势Token占比由34.65%提高到41.85%，并通过恢复率衰减解释最终精度未显著提升的原因。
- 标准GRPO将pass@1从5.08%提升至29.69%；同为60步时，GRPO以26.37%获得更高pass@1，PPO以37.30%获得更高pass@5但训练慢2.24倍，完成准确率、生成多样性与系统成本的定量分析。

## 面试叙事主线

可以按以下逻辑讲，不需要编造“效果大幅领先”的故事：

1. 最初目标不是复现TinyZero，而是研究小模型RLVR训练到后期为什么有效梯度迅速减少。
2. 实验发现，模型学会统一输出合法格式后，大量8条回答同奖，GRPO组内归一化优势变为0；同时还发现float32残差会把理论零优势误记成有效优势。
3. 因此实现零方差显式分支和按Prompt重采样。它确实提高了有效训练信号并带来早期pass@5优势，但100步最终精度没有稳定领先，说明更多非零梯度不等于更好的泛化。
4. 为判断这是GRPO特有问题还是探索不足，又补充带独立Critic的PPO。PPO保持更高熵和pass@5，但pass@1较低、Critic解释能力弱且成本约为标准GRPO的2.24倍。
5. 最终结论不是“某算法全面胜出”，而是：当前预算下GRPO更适合追求单次命中率和训练效率；PPO候选覆盖更广；Adaptive策略需要根据在线恢复率动态关闭，而非后期无差别追加rollout。

## 不应写入简历的说法

- “Adaptive GRPO显著提升最终准确率”：100步时两组pass@1只差2题，且Adaptive更低。
- “PPO准确率达到37.30%”：37.30%是pass@5；PPO的pass@1是23.63%。
- “自主实现PPO算法”：PPO主体来自veRL，个人工作是配置、适配、资源优化、跑通与实验分析。
- “证明GRPO全面优于PPO”：PPO的pass@5高于GRPO，结论取决于单次命中率、候选覆盖率和成本目标。
- “完成多随机种子统计显著性验证”：当前只有固定种子42的一次正式运行，尚不能声称统计显著。
